# **App Name**: Placenta Pathfinder

## Core Features:

- Reference Links: Display links that open modals with (1) how-to use guides and (2) a picture atlas for histopathologic reference, organized in tabs by lesion type.
- Input Form: Allow users to input gestational age (weeks+days), placental weight, and birth type (singleton, twin, triplet). Also calculate and display the estimated placental weight percentile using Pinar et al. reference data for singleton and twin placentas.
- Checklist by Compartment: Organize choices by placental compartment (umbilical cord, membranes, placental villi, maternal decidua, etc.) using checkboxes for significant alterations.
- Tooltip References: Add tooltips to each alteration that link to picture examples of findings.
- AI-Powered Report Summary: Generate a plain-text output summarizing user choices in a standard fashion using AI. This tool will use criteria established in the reference guideline document and provide standardized pathologic terminology as detailed in that paper, informed by user selections.

## Style Guidelines:

- Primary color: Soft blue (#A0C4FF) to evoke a sense of calmness and professionalism, reflecting the medical context of the application.
- Background color: Light gray (#F0F4F8) for a clean, neutral backdrop that ensures readability and minimizes distraction.
- Accent color: Pale orange (#FFB347) to draw attention to key interactive elements and important information, creating a gentle contrast without overwhelming the user.
- Font pairing: 'Belleza' (sans-serif) for headlines, lending an air of sophisticated design and immediate visual appeal combined with 'Alegreya' (serif) for body text
- Use clear, universally recognizable icons to represent different placental compartments and alterations, enhancing usability.
- Employ a clean, three-section layout with a header for inputs and links, a central checklist section, and a bottom text output area.
- Subtle transitions and animations to provide feedback on user interactions and enhance the app's responsiveness.
